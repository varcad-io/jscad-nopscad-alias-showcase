# JSCAD + NopSCAD Alias Showcase

This repository demonstrates:

- JSCAD as the host language
- NopSCAD loaded through the package-style alias form `@nopscad/...`
- composition of library output with native JSCAD primitives

Suggested linked libraries:

- `JSCAD Modeling`
- `NopSCAD`
